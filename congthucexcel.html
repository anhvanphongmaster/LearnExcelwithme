TƯ DUY CHỌN HÀM

Chọn hàm theo câu hỏi công việc

Tôi muốn…

  • Cộng theo điều kiện → SUMIF / SUMIFS
  • Đếm theo điều kiện → COUNTIF / COUNTIFS
  • Tra mã → lấy tên/giá → XLOOKUP (hoặc VLOOKUP)
  • Đúng/Sai theo rule → IF / IFS
  • Lấy tháng/năm từ ngày → MONTH / YEAR

Quy tắc vàng

  • Luôn bắt đầu bằng =
  • Tham chiếu tuyệt đối ($A$1) khi kéo công thức mà không muốn đổi ô
  • Đặt tên vùng (Named Range) nếu dùng nhiều lần
  • Kiểm tra kết quả bằng vài dòng mẫu trước khi áp cả cột
VÍ DỤ QC

3 công thức trên bảng Lot / Model / Input / NG

Giả sử cột: A Ngày · B Lot · C Model · D Input · E NG. Hàng 1 là tiêu đề, dữ liệu từ hàng 2.

  1. NG Rate từng dòng: =IF(D2=0,"",E2/D2) rồi định dạng %.
  2. Tổng NG một Model: =SUMIF(C:C,"ABC-01",E:E)
  3. Đếm lot NG Rate > 5%: thêm cột F là NG Rate, rồi =COUNTIF(F:F,">5%") (hoặc COUNTIFS nếu lọc thêm Model).

Nên

  • Kéo công thức trên Table (cột tự giãn)
  • Khóa ô tiêu thức bằng $ khi cần
  • Đối chiếu 2–3 dòng bằng máy tính tay

Tránh

  • Chia cho Input = 0 mà không bọc IF
  • VLOOKUP khi mã không ở cột trái — dùng XLOOKUP
  • Copy giá trị rồi xóa công thức khi còn phải cập nhật
Bài tập: Tạo cột NG Rate + 1 ô tổng NG của Model bạn chọn. Xong quiz (+25 XP) rồi sang Filter & Sort.
