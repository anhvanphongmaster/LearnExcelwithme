📊 Pivot Table là gì?

Pivot Table là công cụ trong Excel giúp tổng hợp, phân tích và thống kê một lượng lớn dữ liệu một cách nhanh chóng.

Pivot Table đặc biệt hữu ích khi làm báo cáo sản xuất, chất lượng, doanh số và phân tích dữ liệu.

📝 Cách tạo Pivot Table

Bước 1:

Chọn toàn bộ bảng dữ liệu cần phân tích.

Bước 2:

Vào menu Insert → PivotTable.

Bước 3:

Chọn vùng dữ liệu và chọn nơi muốn đặt Pivot Table.

Bước 4:

Kéo các trường dữ liệu vào Rows, Columns, Values và Filters.

Bước 5:

Kiểm tra kết quả và điều chỉnh cách tính toán nếu cần.

💡 Ví dụ

Giả sử bạn có dữ liệu sản xuất:

Lot No Model NG Qty OK Qty
LOT001 FPC-A 5 187
LOT002 FPC-A 3 189
LOT003 FPC-B 8 184
LOT004 FPC-B 2 190

Bạn có thể sử dụng Pivot Table để tổng hợp NG Qty theo từng Model hoặc từng Lot.

🎯 Các khu vực quan trọng

Rows:

Dùng để nhóm dữ liệu theo hàng.

Columns:

Dùng để chia dữ liệu theo cột.

Values:

Dùng để tính Sum, Count, Average...

Filters:

Dùng để lọc dữ liệu theo điều kiện.

🧩 Cách kéo trường trong Pivot Table

Ví dụ với dữ liệu: Lot No, Model, NG Qty, OK Qty

Rows

Model

Hiển thị từng Model theo hàng.

Columns

Chưa sử dụng

Có thể dùng để chia dữ liệu theo cột.

Values

Sum of NG Qty

Tính tổng NG Qty cho từng Model.

Filters

Lot No

Lọc báo cáo theo Lot khi cần.

📊 Ví dụ Pivot Table thực tế

Giả sử bạn có bảng dữ liệu sản xuất như sau:

Lot No Model NG Qty OK Qty
LOT001 FPC-A 5 187
LOT002 FPC-A 3 189
LOT003 FPC-B 8 184
LOT004 FPC-B 2 190

Nếu kéo Model vào Rows và NG Qty vào Values, Pivot Table sẽ tổng hợp thành:

Model Tổng NG Qty
FPC-A 8
FPC-B 10

Như vậy bạn có thể thấy nhanh Model nào có tổng số lỗi cao hơn mà không cần tính thủ công.

📈 Ví dụ phân tích NG Rate

Ngoài NG Qty, trong sản xuất chúng ta còn có thể theo dõi tỷ lệ lỗi của từng Model.

Model Input Qty NG Qty NG Rate
FPC-A 384 8 2.08%
FPC-B 384 10 2.60%

Công thức: NG Rate = NG Qty / Input Qty × 100%

Trong ví dụ này, FPC-B có NG Rate cao hơn FPC-A nên cần được ưu tiên kiểm tra nguyên nhân.
