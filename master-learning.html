Excel Master — kỹ năng nâng cao thực chiến

Đi sâu vào những kỹ năng Excel giúp xử lý dữ liệu nhanh hơn, ít lỗi hơn và xây được quy trình làm việc thực tế.

Thứ tự khuyến nghị: Power Query → Dynamic Array → XLOOKUP → LET → PivotTable → Kiểm soát chất lượng dữ liệu. Đây là nhóm kỹ năng có tính ứng dụng cao trước khi đi sâu vào VBA/Macro.
01

Power Query — gộp & làm sạch dữ liệu

Dùng khi mỗi ngày/tuần bạn nhận nhiều file có cùng cấu trúc. Thay vì copy-paste, Power Query đọc cả thư mục, chuẩn hóa dữ liệu và chỉ cần Refresh khi có file mới.

  • From Folder → Combine Files
  • Đổi kiểu dữ liệu trước khi tính toán
  • Trim/Clean, Remove Blank, Remove Duplicates
  • Merge Queries thay VLOOKUP cho bảng lớn
Bài thực chiến: gộp 10 file nhập liệu thành một Master, thêm cột Source File và kiểm tra thiếu dữ liệu.
02

Dynamic Array — công thức tự đổ

FILTER, UNIQUE, SORT và SEQUENCE giúp thay nhiều cột phụ và giảm thao tác kéo công thức.

=SORT(UNIQUE(FILTER(A2:A1000,B2:B1000="NG")))
  • Tạo danh sách lỗi không trùng
  • Lọc theo nhiều điều kiện
  • Tạo báo cáo tự mở rộng khi dữ liệu tăng
Bài thực chiến: tạo danh sách Lot có NG tự động từ Master Data.
03

XLOOKUP — tra cứu an toàn hơn

XLOOKUP đọc dễ hơn VLOOKUP, tìm được cả trái và phải, và có giá trị trả về khi không tìm thấy.

=XLOOKUP(A2,Master[Lot],Master[Model],"Không tìm thấy")
  • Tra Model/MPN theo Lot
  • Không phụ thuộc số thứ tự cột
  • Kết hợp nhiều điều kiện bằng khóa ghép
Bài thực chiến: map MPN, Model, Process từ bảng chuẩn vào dữ liệu kiểm tra.
04

LET — công thức dài nhưng vẫn đọc được

LET đặt tên cho các phần trong công thức, giúp Excel tính ít lần hơn và người khác dễ sửa.

=LET(input,C2,ng,D2,rate,IFERROR(ng/input,0),rate)
  • Giảm lặp biểu thức
  • Dễ debug công thức dài
  • Phù hợp KPI/NG Rate nhiều điều kiện
Bài thực chiến: viết một công thức NG Rate có xử lý Input = 0.
05

PivotTable — từ dữ liệu sang báo cáo

PivotTable nên là kỹ năng bắt buộc khi dữ liệu đã ở dạng bảng chuẩn. Dùng để trả lời nhanh: lỗi nào nhiều nhất, line nào xấu nhất, tuần nào tăng NG.

  • Rows = Defect / Line / Model
  • Values = Count, Sum, Average
  • Slicer/Timeline để lọc nhanh
  • Refresh sau khi nguồn dữ liệu cập nhật
Học PivotTable →Tiếp Pareto →
06

Data Quality — ngăn lỗi trước khi báo cáo

File tốt không chỉ có công thức đúng. Trước khi tạo Pivot/Dashboard, phải kiểm soát dữ liệu đầu vào.

✓ Không merge ô trong data table
✓ Mỗi cột chỉ một kiểu dữ liệu
✓ Không có hàng tổng chen giữa data
✓ Có ID/Lot/Date rõ ràng
✓ Dùng Table (Ctrl+T)
✓ Kiểm tra duplicate & blank
Quy tắc: nếu nguồn dữ liệu chưa sạch, đừng vội làm Dashboard.

VÍ DỤ MASTER LOT

UNIQUE + XLOOKUP trên Master Lot

Sheet Lots: Lot, Model, Line, Input. Sheet Defects: Lot, NG, Loại lỗi. Đừng VLOOKUP cả cột rồi mới lọc.

  1. =UNIQUE(Lots[Model]) ra danh sách model.
  2. =XLOOKUP(Lot, Lots[Lot], Lots[Model], "") gắn model vào từng dòng NG.
  3. =SUMIFS(Defects[NG], Defects[Model], model) tổng NG theo model.
  4. Lỗi thường gặp: khóa không trùng (space, hoa thường) → TRIM + UPPER trước.
Bài tập: Lấy Top 3 model theo NG mà không copy-paste. Xong quiz rồi sang Power Query.
