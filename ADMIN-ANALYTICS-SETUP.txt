ADMIN ANALYTICS - CÀI ĐẶT

1. Upload toàn bộ file trong ZIP lên GitHub Pages.

2. Vào Supabase Dashboard → SQL Editor.

3. Mở file:
   analytics-setup.sql

   Copy toàn bộ nội dung và Run.

4. Đặt tài khoản của BẠN thành Admin.
   Trong analytics-setup.sql có câu lệnh mẫu ở cuối:

   update public.profiles
   set is_admin = true
   where id = (
     select id from auth.users
     where email = 'YOUR_EMAIL@example.com'
   );

   Thay YOUR_EMAIL@example.com bằng email bạn đang dùng để đăng nhập website
   rồi Run riêng câu lệnh đó.

5. Mở:
   https://doananhtuant02.github.io/LearnExcelwithme/admin.html

6. Đăng nhập bằng tài khoản Admin.

DỮ LIỆU ĐƯỢC GHI NHẬN
- page_view
- login
- excel_mobile_open
- excel_tool_used
- visitor_id ngẫu nhiên
- user_id nếu đã đăng nhập
- timestamp

KHÔNG GHI NHẬN
- Nội dung file Excel
- Giá trị trong ô Excel
- Tên file Excel
- Workbook upload
- Mật khẩu

=========================================================
NẾU VẪN BỊ CHẶN DÙ is_admin = true VÀ ĐÃ CÓ HÀM admin_*
=========================================================

1) Reload schema cache PostgREST (SQL Editor):

NOTIFY pgrst, 'reload schema';

2) Đảm bảo grant còn hiệu lực:

grant execute on function public.is_admin_user() to authenticated;
grant execute on function public.admin_analytics_summary(integer) to authenticated;
grant execute on function public.admin_analytics_trend(integer) to authenticated;
grant execute on function public.admin_analytics_top_tools(integer,integer) to authenticated;
grant execute on function public.admin_analytics_top_pages(integer,integer) to authenticated;
grant execute on function public.admin_learning_summary() to authenticated;
grant execute on function public.admin_learning_funnel() to authenticated;

3) Trên website live:
   - Đăng xuất
   - Tab ẩn danh → auth.html?redirect=admin.html
   - Login email doananhtuant02@gmail.com
   - Xem dòng chữ lỗi mới trên admin (đã chi tiết hơn)

4) Kiểm tra API key trên live (supabase-config.js):
   Supabase Dashboard → Project Settings → API
   Dùng khóa "anon" / "publishable" public (không dùng service_role).
