Chính sách quyền riêng tư

Cách website xử lý tài khoản, BXH, file thực hành và dữ liệu trên máy bạn.

Cập nhật: 27/08/2026
Nguyên tắc ngắn

Website chỉ lấy dữ liệu cần để chạy tài khoản, xếp hạng, tải file và hỗ trợ học. Không bán thông tin học viên. File Excel bạn mở trong Excel Mobile được xử lý trên máy bạn, không tự upload nội dung workbook lên server.

1. Dữ liệu tài khoản

Khi đăng ký / đăng nhập, hệ thống (Supabase) lưu tên đăng nhập hoặc email, mật khẩu đã mã hóa, tên hiển thị và mã tài khoản. Dùng để xác thực, tải file thực hành, Excel Race và bảng xếp hạng.

Tài khoản cũ đăng ký bằng email vẫn dùng được. Không yêu cầu mật khẩu Microsoft / Microsoft 365.

2. Bảng xếp hạng và tiến độ học

BXH học tập có thể hiện tên hiển thị, chuỗi ngày học, XP. Excel Race có thể hiện tên, chuỗi / cấp khi bạn chơi mode Rank.

Tiến độ quiz, XP, badge có thể lưu localStorage trên trình duyệt và đồng bộ lên tài khoản khi đã đăng nhập.

3. Tải file thực hành

Một số file chỉ tải khi đã đăng nhập. Hệ thống có thể ghi nhận tài khoản đã yêu cầu tải (không gửi nội dung file Excel của bạn lên trừ khi bạn chủ động dùng chức năng gửi file).

4. Ý tưởng, thắc mắc, vote, gửi file

Khi bạn gửi ý tưởng / thắc mắc: tên và nội dung được lưu để admin đọc.

Khi gửi file nhờ xử lý: file nằm trên kho Storage, kèm tên, Gmail hoặc Zalo bạn điền để trả lời. Đừng gửi file có dữ liệu mật (lương, CCCD, mật khẩu).

Vote “cần hướng dẫn” được gắn với tài khoản / trình duyệt để mỗi bài chỉ vote một lần.

5. Form liên hệ

Form trên trang Liên hệ có thể gửi qua Formspree hoặc dịch vụ tương đương tới hộp thư quản trị. Nội dung gồm các trường bạn điền trên form.

6. Excel Mobile

File bạn chọn được đọc ngay trên trình duyệt để xem và xử lý. Công cụ không chủ động tải nguyên workbook lên máy chủ để làm các thao tác hiện có. Nên giữ bản sao file gốc và hạn chế đưa dữ liệu cực kỳ nhạy cảm vào công cụ online.

7. Thống kê sử dụng

Website có thể ghi lượt xem trang, bấm tải, mở video, chơi Race, đăng nhập. Có thể dùng mã khách ngẫu nhiên trong localStorage. Nếu đã đăng nhập, sự kiện có thể gắn với mã tài khoản.

Không đưa nội dung ô Excel hay toàn bộ workbook vào bảng thống kê.

8. Cookie / lưu trình duyệt

Dùng localStorage và phiên đăng nhập để nhớ tài khoản, giao diện, tiến độ. Không chạy quảng cáo bên thứ ba theo hành vi.

9. Xóa dữ liệu

Muốn xóa tài khoản, tên trên BXH hoặc file đã gửi: vào trang Liên hệ và nêu rõ tên đăng nhập / email. Quản trị viên sẽ xóa trên Supabase và BXH trong phạm vi kỹ thuật cho phép.

10. Thay đổi chính sách

Khi thêm tính năng mới, ngày cập nhật trên trang này sẽ đổi. Việc tiếp tục dùng website sau ngày cập nhật được hiểu là bạn đã đọc phiên bản mới.
