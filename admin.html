Không có quyền truy cập

Hãy đăng nhập bằng tài khoản đã được cấp quyền Admin.

  1. Mở Đăng nhập bằng nút bên dưới.
  2. Đăng nhập đúng email admin của bạn.
  3. Nếu vẫn bị chặn: vào Supabase → SQL Editor chạy lệnh đặt is_admin = true (xem HUONG-DAN bên dưới).
Đăng nhập tài khoản Admin ← Về trang chủ
Hướng dẫn cấp quyền Admin (Supabase) 
update public.profiles
set is_admin = true
where id = (
  select id from auth.users
  where email = 'EMAIL_CUA_BAN@example.com'
);

-- Kiểm tra:
select id, display_name, is_admin
from public.profiles
where is_admin = true;

Thay email bằng email bạn dùng để đăng nhập website, rồi Run trong Supabase SQL Editor.
