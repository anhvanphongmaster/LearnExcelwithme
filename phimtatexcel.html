STT PHÍM TẮT CHỨC NĂNG
1 Ctrl + N Tạo workbook mới

8 Ctrl + Y Làm lại thao tác

11 Ctrl + V Dán dữ liệu

14 Ctrl + I In nghiêng
15 Ctrl + U Gạch chân
16 Ctrl + 1 Mở Format Cells
17 Ctrl + ; Chèn ngày hiện tại
18 Ctrl + Shift + ; Chèn thời gian hiện tại
19 Ctrl + Space Chọn toàn bộ cột
20 Shift + Space Chọn toàn bộ hàng
21 Ctrl + Shift + $ Định dạng tiền tệ
22 Ctrl + Shift + % Định dạng phần trăm
23 Alt + = Tự động tính tổng
24 F2 Chỉnh sửa ô
25 F4 Lặp lại thao tác / cố định tham chiếu
26 Ctrl + Page Up Chuyển sang sheet bên trái
27 Ctrl + Page Down Chuyển sang sheet bên phải
28 Ctrl + Shift + L Bật / tắt Filter
29 Ctrl + T Tạo Table
30 Ctrl + W Đóng workbook

32 Ctrl + Shift + Tab Chuyển ngược giữa workbook
33 Ctrl + Shift + + Chèn ô, hàng hoặc cột
34 Ctrl + - Xóa ô, hàng hoặc cột
35 Ctrl + D Fill Down - sao chép xuống
36 Ctrl + R Fill Right - sao chép sang phải
37 Ctrl + Home Đi đến ô A1
38 Ctrl + End Đi đến ô cuối vùng dữ liệu
39 Home Về đầu hàng
40 End Đi đến chế độ End
41 Page Up Cuộn lên một màn hình
42 Page Down Cuộn xuống một màn hình
43 Alt + Enter Xuống dòng trong cùng một ô
44 Ctrl + Enter Nhập cùng dữ liệu vào nhiều ô
45 Esc Hủy thao tác đang thực hiện
46 Ctrl + Arrow Di chuyển nhanh đến mép vùng dữ liệu

48 Ctrl + Shift + 1 Định dạng số
49 Ctrl + Shift + 4 Định dạng tiền tệ
50 Ctrl + Shift + 5 Định dạng phần trăm
51 Ctrl + Shift + 6 Định dạng số mũ
52 Ctrl + Shift + 7 Thêm đường viền ngoài
53 Ctrl + Shift + ~ Định dạng General
54 Ctrl + K Chèn hyperlink
55 Ctrl + G Mở Go To
56 Ctrl + Shift + U Mở rộng / thu gọn thanh công thức
57 Ctrl + F1 Ẩn / hiện Ribbon
58 Alt + F1 Tạo biểu đồ nhanh

60 Alt + F8 Mở hộp thoại Macro
