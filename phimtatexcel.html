⌨️ Phím tắt Excel cần biết

Những phím tắt thường dùng giúp bạn làm việc nhanh và hiệu quả hơn.

STT Phím tắt Chức năng
1 Ctrl + C Sao chép
2 Ctrl + V Dán
3 Ctrl + X Cắt
4 Ctrl + Z Hoàn tác
5 Ctrl + Y Làm lại thao tác
6 Ctrl + S Lưu file
7 Ctrl + F Tìm kiếm
8 Ctrl + H Tìm và thay thế
9 Ctrl + A Chọn vùng dữ liệu
10 Ctrl + P Mở hộp thoại in
11 Ctrl + N Tạo workbook mới
12 Ctrl + O Mở file
13 Ctrl + W Đóng workbook
14 Ctrl + B In đậm
15 Ctrl + I In nghiêng
16 Ctrl + U Gạch chân
17 Ctrl + 1 Mở Format Cells
18 Ctrl + ; Nhập ngày hiện tại
19 Ctrl + Shift + : Nhập thời gian hiện tại
20 Alt + = Tự động tính tổng
21 F2 Chỉnh sửa ô
22 F4 Lặp lại thao tác / khóa tham chiếu
23 F5 Mở Go To
24 F7 Kiểm tra chính tả
25 F11 Tạo biểu đồ
26 Ctrl + Home Về ô A1
27 Ctrl + End Đến ô cuối vùng dữ liệu
28 Ctrl + ↑ Di chuyển đến đầu vùng dữ liệu
29 Ctrl + ↓ Di chuyển đến cuối vùng dữ liệu
30 Ctrl + Shift + L Bật / tắt Filter
