Kiểm tra kiến thức và luyện tập các kỹ năng Excel đã học trên website.

🧠 Bài tập cơ bản

Cơ bản

1. Tính NG Rate

Một Lot có Input Qty = 500 và NG Qty = 15. NG Rate bằng bao nhiêu?

Đáp án:

NG Rate = 15 / 500 = 3%

Công thức Excel:

=15/500
Cơ bản

2. Hàm IF

Nếu NG Rate nhỏ hơn hoặc bằng 3% thì hiển thị PASS, ngược lại hiển thị NG.

Đáp án: =IF(A2<=3%,"PASS","NG")
Trung bình

3. Pivot Table

Bạn có dữ liệu gồm Model, Lot No, Input Qty và NG Qty. Hãy tổng hợp tổng NG Qty theo Model.

Gợi ý:

Rows → Model

Values → Sum of NG Qty
