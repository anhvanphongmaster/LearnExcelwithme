8 bài từ dữ liệu thô đến Master Data

Không học Power Query theo kiểu nhớ nút. Khóa này đi theo một quy trình công việc thật: nhận nhiều file nhập liệu, làm sạch, gộp, đối chiếu, kiểm tra chất lượng và tạo một Master có thể Refresh khi có file mới.

Lộ trình 8 bài

Mỗi bài giải quyết một phần của cùng một bài toán. Học đúng thứ tự để đến bài 8 bạn có thể tự xây quy trình Refresh thay cho copy-paste.

01

Get Data & Power Query Editor

Nền tảng

Hiểu Query, Applied Steps và cách Excel ghi lại từng bước biến đổi.

  • Data → Get Data
  • Close & Load vs Close & Load To...
  • Kiểm tra tên cột và kiểu dữ liệu
02

Làm sạch dữ liệu đúng cách

Data Cleaning

Chuẩn hóa dữ liệu trước khi gộp để tránh lỗi âm thầm trong báo cáo.

  • Trim / Clean
  • Remove Blank / Duplicates
  • Uppercase Model
  • Đổi Data Type
03

Append Queries

Gộp dòng

Dùng Append khi nhiều bảng có cùng cấu trúc và cần nối thành một bảng dài.

  • Append Two / Three or more tables
  • Kiểm tra số dòng sau Append
  • Giữ Source để truy vết
04

Merge Queries

Đối chiếu

Dùng Merge để map MPN/Model hoặc ghép bảng master thay cho VLOOKUP trên dữ liệu lớn.

  • Left Outer Join
  • Chọn khóa ghép đúng
  • Expand đúng cột cần lấy
05

From Folder — tự động gộp file

Quan trọng nhất

Đọc cả thư mục thay vì import từng file. File mới được thêm vào sẽ xuất hiện sau Refresh.

  • Get Data → From Folder
  • Combine & Transform
  • Sample File / Transform File
06

Data Quality & kiểm tra thiếu

QC

Không chỉ gộp được — phải biết dữ liệu có đủ và sạch hay không.

  • Column Quality / Distribution
  • Null / Error / Empty
  • Đếm Source File
  • Kiểm tra 4.150 dòng kỳ vọng
07

Refresh & quy trình vận hành

Tự động hóa

Thiết kế quy trình để người dùng chỉ thay file trong thư mục rồi bấm Refresh All.

  • Refresh Preview / Refresh All
  • Query Dependencies
  • Chỉ Load bảng cuối
08

Project: 10 file → Master 4.150 dòng

Final Project

Gộp toàn bộ bộ dữ liệu thực hành, chuẩn hóa Staff/Model, giữ Source File và đối chiếu checkpoint bên dưới.

  • 10 file × 415 dòng
  • Chuẩn hóa text
  • Master refresh-ready
